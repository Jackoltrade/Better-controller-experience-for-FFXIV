# PS5 DualSense Controller for FFXIV

[English](README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md)

FFXIVで **DualSense** / **DualSense Edge** のライトと振動を自分好みに調整できる、Dalamud用プラグインです。

**公開テスト版 · Windows x64 · USB接続専用 · Dalamud API 15**

[ソースコード](https://github.com/Jackoltrade/PS5-DualSense-Controller-for-FFXIV-) · [リリース](https://github.com/Jackoltrade/PS5-DualSense-Controller-for-FFXIV-/releases) · [不具合を報告](https://github.com/Jackoltrade/PS5-DualSense-Controller-for-FFXIV-/issues)

![コントローラーのプレビュー画像](src/DualSenseLighting/Assets/dualsense-preview.png)

## 主な機能

- **RGBライト：** 単色、レインボー、ゆっくり明滅、2色グラデーション、オーロラ、炎、ハートビート、コメット、レインボーパルスと、音に連動する2種類の効果。
- **下側のLED：** タッチパッド下の5つの白いライトの点灯数や動き方を選んだり、LBの状態を表示したりできます。
- **戦闘音の振動：** 自分のスキルや武器の音を、ゲーム標準のDualSense振動処理に送って振動に変えます。
- **音の方向と距離：** キャラクターを中心に、カメラの向きに合わせて左右のグリップを振動させ、遠い音は弱めます。
- **足音の振動を強化：** ゲーム標準の足音振動だけを、戦闘音とは別に強められます。マウントの振動はそのままです。
- **プレビューとメーター：** コントローラーと同じ計算によるライト表示と、感度調整に使える反応メーターを備えています。
- **日本語・英語・簡体字中国語：** タブ上部で切り替えられ、選んだ言語は保存されます。

別のアプリに切り替えると、カスタムライトを一度消灯してライトの制御を手放し、追加の戦闘・足音振動も一時停止します。標準のスピーカー音やアダプティブトリガーは維持されます。ゲームに戻るかコントローラーを接続し直すと、設定が再び反映されます。

## 動作環境と現在の対応状況

- Windows x64、**Dalamud API 15**を使用するFFXIV、USB接続のソニー製DualSense / DualSense Edgeが必要です。
- 振動機能を使うには、ゲーム内でコントローラーの振動を有効にしてください。スピーカー音などは、ゲーム標準のDualSense設定も必要です。
- Bluetooth接続、仮想コントローラー、ボタンの割り当て変更には現在対応していません。

本プラグインは、カスタムリポジトリ向けの**公開テスト版**です。Dalamud公式リポジトリの審査を受けたプラグインではありません。ネイティブの音声・カメラ処理は、XIVLauncherCNとクライアント `2026.10.06.0000.0000` で検証されています。他リージョンのクライアントや今後のパッチでは、動作確認が必要です。対応していない音声レイアウトでは該当機能を一時停止し、診断タブに理由を表示します。

## 公開テスト版の導入

メンテナーが最初のリリースを公開するとダウンロードできるようになります。リリース一覧が空の場合は、[ソースからビルド](#ソースからビルド)を参照してください。

### Dalamudのプラグインインストーラーを使う

1. `/xlsettings` → Experimental → **Custom Plugin Repositories**を開きます。
2. 最初の公開リリース後、次のURLを追加します。
   ```text
   https://github.com/Jackoltrade/PS5-DualSense-Controller-for-FFXIV-/releases/download/plugin-repository/pluginmaster.json
   ```
3. Dalamudでテスト版プラグインを有効にし、`/xlplugins`で **PS5 DualSense Controller for FFXIV** を検索してテスト版をインストールします。
4. コントローラーをUSB接続し、`/ds5`を実行します。

このリポジトリは**テスト版専用**です。現在のビルドを安定版として配信することはありません。

### 手動でテストする

1. [公開テストリリース](https://github.com/Jackoltrade/PS5-DualSense-Controller-for-FFXIV-/releases)から `latest.zip` をダウンロードします。
2. ZIP全体を専用のフォルダーに展開します。
3. `/xlsettings` → Experimental → **Dev Plugin Locations** に、そのフォルダーの `DualSenseLighting.dll` を追加します。
4. `/xlplugins` → Dev Toolsでプラグインを有効にします。

以前の **Steam Lighting Guard** は先に無効にしてください。同時に複数の方法で読み込まないよう、通常のインストーラーへ移行する際は開発用プラグインの登録を削除してください。

プロジェクト名は変わりましたが、既存の設定と開発用パスを引き継ぐため、DLL名と内部IDは `DualSenseLighting` のままです。

## 設定方法

**`/ds5`** で設定を開きます。項目や **(?)** にマウスを合わせると説明が表示されます。グレーの項目は上位の機能を有効にすると操作でき、設定値は保持されます。

初めて設定を開くと、対応コントローラー、USB接続、別のアプリに切り替えたときの動作を説明する案内が表示されます。左上の**使い方**からいつでも開き直せ、案内の中で言語も変更できます。一度閉じると、再読み込みやタブの設定リセットでは自動表示されません。

### チャットコマンド

`/ds5` で設定、`/ds5 help` でコマンド一覧、`/ds5 info` で使い方を開きます。`/ds5 trace` は診断データを15秒間記録します。

`/ds5 <機能名> on`、`off`、`toggle` で、設定画面を開かずに機能をオン・オフ・切り替えできます。例：`/ds5 combathaptics on`。

| 機能名 | 切り替える内容 |
| --- | --- |
| `lighting` | ライトのカスタマイズ |
| `combathaptics` | 自分の戦闘音による追加の振動 |
| `footsteps` | 標準の足音振動の強化 |
| `spatialhaptics` | 音の方向を振動に反映 |
| `distancefade` | 距離による減衰 |
| `followimpact` | スキルの着弾方向への補正 |

大文字・小文字は区別しません。変更は自動保存され、マクロでも使えます。すでにオンの機能に `on` を繰り返しても、確認の振動は再生しません。サブ機能の上位設定は自動でオンにせず、必要な設定をチャットに表示します。`footsteps off` は足音振動を標準の強さに戻し、振動そのものを消すことはありません。

### ライティング

効果、色、明るさ、周期を選べます。左右のサイドライトは同じRGB色を共有します。コントローラーにはLEDを1つずつ制御するインターフェースがないため、ライトに沿って流れる空間的な波は作れません。

| 音に連動するモード | 動き |
| --- | --- |
| 音量連動 | 音が大きいほど1色の光が明るくなり、無音では消えます。 |
| 音量で色変化 | 音が大きくなると「静かな時の色」から「大きな音の色」へ変化します。無音でも静かな時の色で光ります。 |

「自分のキャラクターのみ」は自分のアクションや武器の音に反応します。「すべての戦闘音」は周囲のプレイヤーや敵の音も含めます。この選択はライトにだけ適用され、追加の戦闘振動は常に自分の音を使います。

スキルを使いながら、**音への感度**の下にあるメーターで反応を確認できます。常にいっぱいなら感度を下げ、静かなスキル音でほとんど動かなければ上げてください。小さな音の自動除外は感度に合わせて調整されます。詳細設定では基準を自分で指定できます。ゲームの音量は変わりません。

**下側のLED**では点灯数と動き方を選びます。チェイス・点滅・ローディングは選んだ位置の中で動きます。バウンスときらめきは5つの位置を使い、数の設定は同時に光るLEDの数を表します。ハートビートは選んだ数のLEDが一緒に光ります。LBモードでは、PvEは使用可能なパーティゲージ数、PvPは自分の蓄積量を表示し、自分がLBを使うと速く点滅します。

### 振動

戦闘振動をオンにすると、確認のために短く2回振動します。スキルを使っていなくても反応します。強さの変更やゲームに戻ったときには繰り返しません。

初回の設定は次のとおりです。

| 設定 | 初期値 |
| --- | --- |
| 自分の戦闘音で振動 | オン、強さ80% |
| 音の方向を振動に反映 | オン |
| スキルの着弾方向に寄せる | オン、強さ100% |
| 距離を測る基準 | キャラクター |
| 距離による減衰 | 推奨設定：3mまで最大、25mで停止 |
| 標準の足音振動を強化 | オフ、倍率の保存値150% |

方向の判断にはキャラクターの位置とカメラの向きを使います。「スキルの着弾方向に寄せる」は、キャラクター付近の音の振動を、自分のスキルの直近の着弾方向へ寄せます。変えるのは方向だけで、実際の音源の位置や距離は変わりません。

キャラクターを基準にした距離減衰は、カメラのズームに影響されません。別の選択肢としてカメラ基準もあり、推奨範囲はキャラクターとカメラの距離を加えて調整します。手動の範囲は距離の詳細設定にあります。ジョブやスキルで音の作りが異なるため、振動の強さにも違いがあります。

**標準の足音振動を強化**する機能は、ゲームがすでに振動として送っている足音だけを強めます。戦闘音とは独立して動き、マウント中や別のアプリの操作中は一時停止します。範囲は100～600%で、100%では元の強さのままです。スピーカー音やマウントの振動は強めません。

**初期設定に戻す**を押すと確認画面が表示され、現在のライティングまたは振動タブだけを初期化します。キャンセル、閉じる、Escape、ポップアップの外側のクリックでは変更しません。言語ともう一方のタブは維持され、アップデートでも既存の設定を引き継ぎます。

### 診断とお問い合わせ

診断タブには接続・フォーカス状態、出力エラー、音の発生元に関するカウンター、左右の振動メーター、LBの状態がまとまっています。

特定の音を調べたい場合：

1. 音に連動するライト、または戦闘音の振動を有効にします。
2. **`/ds5 trace`** を実行するか、診断タブの15秒間の記録ボタンを押します。
3. カウントダウン中に対象のスキルを使い、完了の表示が出たら止めます。

DLLと同じ場所の `sfx-trace.json` を上書きします。音の名前、発生元、位置、振動の経路、ローカルプロセスのアドレスを記録しますが、**音声は録音しません**。自動送信もしません。公開の不具合報告に添付する前に、内容を確認してください。

## よくある質問

**別のアプリに切り替えると消灯する。** 制御を引き渡すための意図した動作です。ほかのソフトが次にライトの指示を送ると、その設定が反映されます。本プラグインからSteamなどの設定を強制的に再適用することはできません。

**標準の振動はあるのに、戦闘音の振動がない。** USB接続、戦闘音の振動がオン、強さが0でないことを確認し、診断タブを見てください。遠い着弾音は距離の上限を超えている場合があります。方向と距離の設定が有効な時は、位置不明の音を除外します。標準の振動と追加のスキル振動は別の経路です。

**アニメーションが動かないように見える。** ライトのカスタマイズを有効にしてFFXIVを操作しているか確認してください。チェイスには2個以上のLEDが必要です。バウンスで5個を選ぶと全体が光るため、移動が見えなくなります。

**SteamやDS4Windowsと一緒に使える？** 共有ハンドルを使い、バックグラウンドではライトの制御を手放します。ただし、FFXIVの操作中でも、ほかのソフトは独自の指示を送れます。設定を分かりやすくするには、ゲーム中のライトは本プラグインに任せ、標準のDualSense対応を維持する構成がおすすめです。

## ソースからビルド

**.NET 10 SDK** と対応するDalamud API 15のライブラリを用意し、リポジトリのルートで実行します。

```powershell
./tools/build.ps1 -DalamudLibPath 'C:\path\to\Dalamud'
```

ローカルのXIVLauncher / XIVLauncherCNのライブラリを自動検出でき、`DALAMUD_HOME`も使えます。本プロジェクトのWSL開発環境では、既存のWindowsランタイムとローカルのRoslynコンパイラーで次の方法も使えます。

```bash
python3 tools/build-wsl.py
```

どちらも最適化したx64コードをビルドし、コントローラー・コア処理・翻訳のチェックと、DLL名・バージョン・APIの照合を行ってから `artifacts/plugin/` に出力します。オフライン用コンパイラーは配布物に含めません。`-Probe` / `--probe`ではUSBの機能を読み取るだけで、出力コマンドを送りません。

```bash
python3 -m unittest discover -s tests -p 'test_*.py'
python3 tools/package-release.py
```

`artifacts/release/`に、検証済みの `latest.zip`、テスト版専用の `pluginmaster.json`、チェックサム、リリース概要が作られます。ユーザー設定、診断記録、Dalamud本体、コンパイラーの依存ファイルは含めません。
